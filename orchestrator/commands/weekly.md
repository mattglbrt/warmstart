description: Friday weekly review across every group and project
---
Run the weekly review (PLAYBOOK §5). Keep your own context lean: read only each `STATUS.md`'s header + Now + Blockers + Next (subagents for anything deeper).

1. For each group: status changes this week, top 3 next week, blockers to chase (person + what), deadlines inside 14 days, notes on scope/billing/risk.
2. Flag every `STATUS.md` whose date is older than 14 days — list them as "stale: refresh or mark dormant".
3. Walk `_system/RECURRING.md`: which items happened, which didn't.
4. Refresh `PROJECTS.md` rows that drifted from their STATUS.md. Remove past deadlines that are done; flag past ones that aren't.
5. List any `HANDOFF.md` files that haven't been consumed and anything still sitting in `inbox/`.
6. Write the review to `_system/reviews/YYYY-MM-DD.md` (template: `_system/templates/WEEKLY_REVIEW.md`).
7. Reply with the top 5 things for next week and the chase list.
